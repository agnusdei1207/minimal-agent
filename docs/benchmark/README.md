# 벤치마크 문서 안내

방법론, 개선 원인, 검증 증거를 이 폴더에서 함께 찾는다. 실제 운영 명령은 러너 옆의 런북을 정본으로 사용한다.

| 문서 | 읽는 목적 |
|---|---|
| [방법론](METHODOLOGY.md) | 실행 → 분석 → 분류 → 집계 → 도입의 연구 흐름과 산출물 |
| [신뢰성 개선 보고서](reliability-2026-09-05.md) | 원인과 변경 전후, 검증 명령·결과 |
| [프로젝트 품질 평가](project-audit-2026-09-05.md) | 감사 당시 코어 평가, 미해결 항목, 진단 조건과 관찰 결과 |

평가와 검증은 날짜가 있는 과거 기록이다. 현재 상태는 해당 실행의 증거로 판단한다. 코어 감사는 점수를 해석하는 배경이며 의도된 자율성을 제한하는 정책이 아니다.
