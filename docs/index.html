🧭 Architecture & Offensive Philosophy

Prompt-First over Code-Bloat
Code is debt. Rust runtime enforces OS/IO invariants; tactical tradecraft and observation hygiene live in prompts.
Seams & Tracer Bullets
Targets decomposed into architectural seams. Minimal tracer bullets capture decisive differential server signals.
4-D Orthogonal Bypass
Eliminate depth-first traps via 4 orthogonal axes: context escaping, parser differentials, equivalents, and ES5 compat.
Single-Journal Orchestration
Bounded star topology (1+9). Event-sourced durable recovery with zero external DB or heavy RAG overhead.
