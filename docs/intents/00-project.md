# 프로젝트 인텐트 · pentesting

- 상태: 진행 중
- 작성 2026-09-08
- 갱신: 2026-09-12 14:11 KST

이 문서는 프로젝트가 무엇을 왜 원하는지와 여러 작업에 걸쳐 살아남는 결정·제약을
소유한다. 한 번의 변경 단위 결과는 `docs/intents/0001-*.md` 작업 인텐트에, 코드가
어떤 모듈로 이뤄져 있는지는 `ARCHITECTURE.md`에, 공통 용어는 `GLOSSARY.md`에 있다.
왜 이렇게 결정했는지는 각 작업 인텐트(`docs/intents/0001-*.md`)의 `결정`·`제약`에 흡수돼 있다.
별도의 결정기록 문서는 두지 않는다 — 인텐트가 결정의 단일 정본이다.

## 왜

약한·로컬 LLM(소형 오픈모델 포함)으로도 신뢰성 있게 도는 자율 펜테스팅 팀 에이전트를
만든다. 프롬프트가 아니라 코어가 신뢰성을 보장하도록 설계해서, 모델이 약해도 컨텍스트가
무너지거나 무한 루프에 빠지거나 진행을 조용히 잃지 않게 한다. 레거시 Node `pentesting`을
계승하는 clean-room 순수 Rust 코어다.

## 무엇 (관측 가능한 목적)

- 인가된 교전(authorized engagement)·CTF 범위 안에서 목표를 향해 스스로 정찰·공격·보고한다.
- 하나의 리더(main)와 경계 지어진 팀 트리가 병렬로 작업하고, 검증된 핵심을 위로 정확히 보고한다.
- 컨텍스트가 차면 의미를 보존하며 압축해, 매 턴 재사용 가능한 전장 노트(brief)로 전략을 잇는다.

## 제약 (여러 작업에 걸쳐 살아남는 결정)

- **Clean-room 공개 저장소.** `../pentesting`의 private 소스·프롬프트·비밀·아티팩트를 복사하지 않는다.
- **빌드는 컨테이너 경유만.** host Cargo 금지. 모든 Rust 빌드·테스트·포맷·린트는 `scripts/dbuild.ps1`
  (Docker `rust:1.98`)로, Node는 `scripts/nverify.ps1`(Node 24 LTS), 앱 이미지는 `scripts/dimage.ps1`로 한다.
- **단일 저널 원장 = 무손실.** 모든 사건은 append-only 저널에 남고, 압축·트리밍이 컨텍스트에서 무엇을
  걷어내도 원장에는 보존된다(INTENT-0001 §9).
- **경계 지어진 3단계 팀 트리.** main(depth 0) → child(1) → grandchild(2, leaf). 더 깊게 못 만든다.
  노드당 활성 ≤10. 통신은 이웃(부모·자식·형제)만(INTENT-0004).
- **버전은 모든 표면에서 일치.** SemVer. 현재 `0.200.1`. Cargo·npm·Docker·문서 태그가 어긋나면 실패로 본다.
- **단일 브랜드 `pentesting`(v0.200.0).** 저장소·npm·Docker·CLI·문서 링크를 하나로 일원화(INTENT-0006).
  레거시 `minimal-agent` 별칭·`MINIMAL_AGENT_*` env는 사용자 대면 표면에서 완전 제거했다(2026-09-12,
  INTENT-0006의 별칭 폐기 열린 질문에 대한 답). 데이터 직렬화 호환만 남는다: 저널 마커
  `<!-- minimal-agent:runtime:* -->`와 `.minimal-agent` 상태 디렉터리 폴백(기존 런 재개용).
- **약한 모델 강건성은 코어 불변식이다.** 반사적 거부 방지(execution-mandate)·압축 기계적 폴백·도구 출력
  절단은 특정 프롬프트 파일에 고정돼 있고 흔들지 않는다(INTENT-0002).

## 상시 승인 범위 (사람이 매번 확인하지 않아도 되는 것)

- 모든 작업은 `main` 브랜치에서 한다. branch·worktree·PR을 만들지 않는다.
- commit·push는 명시적으로 요청받을 때만 한다.
- 되돌릴 수 있는 결정(양방향 문)은 스스로 정하고 진행한다. 되돌리기 어려운 결정은 작업 인텐트의
  `열린 질문`으로 올려 사람의 답을 받는다.

## 결정기록

결정기록은 별도 문서가 아니라 각 작업 인텐트가 담당한다. `docs/intents/0001~0006`이 코어·인가교전·셸·
팀트리·브라우저·릴리스의 결정을 흡수했고(과거 ADR 문서를 대체), 새 작업도 인텐트로 시간순으로 쌓는다.
인텐트끼리는 `INTENT-000N`으로 링크한다.
